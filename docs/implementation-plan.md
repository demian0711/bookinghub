# Kế hoạch triển khai

M0 đã hoàn thành. M1 đã triển khai và chạy thử trên Windows với PostgreSQL 17.12 tạm. Hai ứng dụng khởi động qua script dev. Trang chủ, Swagger, health và ready qua proxy trả 200. Khi dừng database, ready trả 503 và health vẫn trả 200. Khi bật lại database, ready trở về 200. Cài đặt frozen, lint, format, typecheck, hai smoke test Jest và build đã đạt. Docker Compose CLI đã đọc được cấu hình với env mẫu. Đã kiểm chứng Docker Compose từ Git Bash trên Windows: db:up đưa PostgreSQL 17.12 về healthy tại 127.0.0.1:5432, hai smoke test đạt với env local, db:down dừng container và giữ volume. Workflow CI chờ lần chạy trên GitHub. M2 đã triển khai API xác thực, phân quyền, seed và migration; đã đạt 2 smoke test và 8 test tích hợp trên PostgreSQL riêng. Luồng qua proxy Next.js trả lần lượt 201, 200, 200, 204 và 401 cho đăng ký, đăng nhập, đọc hồ sơ, đăng xuất và dùng lại cookie. CI đã có bước migrate và test:integration, chờ chạy trên GitHub. M3–M8 là công việc dự kiến. Mỗi hàng có đầu ra đủ nhỏ để review riêng.
